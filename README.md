# WonderShop
Десктоп приложение магазина обуви, реализованное в WPF с частичным MVVM и подключением к базе данных. Позволяет облегчить учет, удаление, добавление и редактирование информации о товарах и управления заказами. В программе реализована ролевая система (админ, менеджер, клиент) с разграничением прав
